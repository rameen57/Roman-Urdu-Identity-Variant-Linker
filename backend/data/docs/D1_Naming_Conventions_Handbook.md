# Naming Conventions Handbook

In the fictional Records Office, every person's name is stored in three parts: given name, father name, and family name. For example, in "Muhammad Ali Khan", "Muhammad" is the given name, "Ali" is the father name, and "Khan" is the family name. Officers should always compare all three parts before deciding whether two records refer to the same person. Roman Urdu has no fixed spelling, so the same person may be written differently across case files. Exact string matching is therefore unreliable. This handbook is the authoritative source for how names are structured in the registry.
