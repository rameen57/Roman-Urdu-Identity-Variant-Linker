# Ambiguity Playbook

Very common names and near-miss names are the main source of false merges. Examples:
- Ali Khan vs Ahmed Khan look similar but are different people (combined score 0.84, tokens differ phonetically).
- Muhammad Ali Khan vs Muhammad Ahmed Khan: phonetic keys differ ("mmmd al xn" vs "mmmd amd xn"), so they are Possible, not Likely same.

When evidence conflicts or confidence is low, escalate to a human supervisor and do not merge. Nicknames are not handled by this system. All names and cases are fictional.
